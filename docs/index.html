Declare the hardware boundary once.

A .chw contract is checked for contradictions and generates the C header, the device tree, the SystemVerilog registers and the rest, so they cannot drift apart.

Real output. Every refusal has a stable code, a tier, a span and a remediation, and every rule has a fixture that must reach it.

Stop maintaining five copies

When a field widens, the driver is wrong silently. When an interrupt link breaks, the device tree is wrong silently. Here the failure is loud and structured.

📄

One source

Registers, fields, interrupts and DMA layouts in one contract. Generators are deterministic, so a diff of a generated file is meaningful.

🚫

Refusals are data

Overlaps, bad alignment, unresolved interrupts and ownership errors come back as codes an agent can match on.

🎯

Impact analysis

diff and impact list which generated artifacts a change invalidates, decided by byte-comparing generator output.

🧾

No over-claiming

A report counts only what ran. A skipped roundtrip is never a pass, and vendor tools stay trust boundaries.

Five targets from one contract

Consumers never need to know cancho-hdl exists.

C header

Structs and volatile accessors. Compiles clean under gcc and clang.

Cancho binding

Typed driver-side declarations.

Device tree

A reg and interrupts fragment.

SystemVerilog

The register file, structurally checked.

CMSIS-SVD

XML validated against the SVD schema.

The generated C header executes the scenario corpus op-for-op against the reference model under gcc and clang. Seeded drift makes the comparison fail, which shows it can.

What is not claimed

Written down so a report cannot imply it.

Not working hardware

Timing, area and vendor IP are trust boundaries, never labelled verified.

No SystemVerilog behaviour check yet

That needs Verilator or cocotb. Only structure is checked today.

Mostly still Python

The textual parser, the JSON loader, the schema validator and the schema-level conformance run are ported. The semantic checker, generators, diff and report remain the Python reference, being replaced.

Try it

The cancho parser needs the cancho compiler. The reference tools need Python 3.

git clone https://github.com/alpibrusl/cancho-hdl.git
cd cancho-hdl
export CANCHO=<path-to-the-cancho-binary>
sh scripts/gate_cancho.sh              # cancho tests, validator and parser vs the Python tools
python3 scripts/run_gate.py           # the reference gate
